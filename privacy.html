The Stream Brief: Privacy Policy

Last updated: 20 November 2026

"Shorts clipper" is a private tool used only by the owner of the YouTube channel The Stream Brief (@thestreambrief) to upload and schedule that channel's own videos. It is not offered to the public, and no one else signs in to it.

What the tool accesses

With the channel owner's permission, given through Google's sign-in, the tool uses the YouTube Data API and YouTube Analytics API to:

  • upload, schedule and update videos on The Stream Brief;
  • add those videos to the channel's playlists, and post comments and likes as the channel;
  • read the channel's own view, subscriber and audience-retention numbers.

What is stored, and where

The sign-in token and the channel's statistics are stored only on the channel owner's own computer. Nothing is sold, shared with third parties, or used for advertising. The tool collects no data about viewers beyond the totals YouTube Analytics reports to the channel owner, and the public comments on the channel's own videos.

Google API Services

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements. It also uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. When it is, the stored token stops working, and it is deleted from the owner's computer.

Contact

Questions: contact the channel through its YouTube page, youtube.com/@thestreambrief.
